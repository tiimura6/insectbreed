# JF育成アプリ (insectbreed)

日本の昆虫を **採集** して、**育てて**、**増やす** ブラウザゲーム。

**遊ぶ: https://tiimura6.github.io/insectbreed/** (スマートフォン推奨。ホーム画面に追加できます)

合同会社常北ファームが、集客を目的に作っています。ゲーム内の商品・価格は実店舗とは関係ありません。

## 遊び方

1. **採集に出かける**: 47都道府県 × 平地/山地 から場所を選び、採集方法(樹液・灯火・朽ち木割り・トラップ)と時間帯を決めて出発。季節・天気・気温・月齢で出会える虫が変わります。採集は月3回まで。はじめての県は出会いやすくなります
2. **持ち帰る虫を選ぶ**: 合うサイズのケースに空きがある虫だけ持ち帰れます。選ばなかった虫は、捕まえずにその場に残します
3. **お世話する**: 幼虫はマット交換、成虫はゼリー、どちらも霧吹き。メーターは現実の時間で減ります
4. **1か月進める**: 幼虫が育ち、蛹になり、季節が来ると羽化します。戻すことはできません
5. **売る・増やす**: ショップの委託販売で売ってポイントを得て、用品やケースを買います。同じ種の雌雄をペアにして産卵セットを組むと、幼虫が生まれます
6. **図鑑を埋める**: 12種+保護種5種。寿命を迎えた成虫は標本にできます

約束: 飼った虫は野外に放しません。保護種は捕まえません(図鑑に「発見」として記録されるだけです)。

## 現状 (v0.5)

- 単一HTML(`index.html`)。サーバーなし。データはブラウザの localStorage に保存(端末をまたがない)。旧データは読み込み時に自動変換
- 採集・飼育・繁殖・委託販売・譲渡・標本・図鑑・自分の記録・はじめての説明
- アニメーション: 移動・捕獲・購入・SOLD・月送りのカレンダー・羽化/孵化カード・お世話のエフェクト・虫の待機モーション・季節の粒子。端末の「視差効果を減らす」設定では止まります
- 種データは環境省・自治体レッドデータブック等の公開資料にもとづく目安で、ゲーム用に簡略化しています。商品名は一般名にしています

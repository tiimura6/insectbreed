# JF育成アプリ (insectbreed)

合同会社常北ファームの集客を目的とした、昆虫育成Webアプリ。

## 現状 (v0)

- `index.html`: 育成画面のみ実装(単一HTML、外部依存はGoogle Fontsのみ)
  - エサ・マット交換・霧吹きで状態メーターが変化
  - ショップ / 採集 / ランキングへフェード遷移(中身は未設計の仮画面)
  - 状態はブラウザの localStorage に保存(端末をまたがない)

## 未実装・未決定

- 採集画面、ショップ画面、ランキング画面
- 時間経過の方式(実時間 or 日次)
- 成長段階(卵・蛹・成虫)
- 店舗連携(QR等)は先送り
- ランキングはサーバー側集計が前提のため保留

## 起動

`index.html` をブラウザで開くだけで動作します。

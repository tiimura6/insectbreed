# JF育成アプリ (insectbreed)

合同会社常北ファームの集客を目的とした、昆虫育成Webアプリ。

## 現状 (v3 プレビュー)

単一HTML(`index.html`)。状態はブラウザの localStorage に保存(端末をまたがない)。旧データは読み込み時に自動変換。

- 育成: 個体別メーター、現実時間での劣化、「1か月進める」で成長・蛹・羽化・寿命・死亡。幼虫はマット交換で自動的にエサを食べる
- 採集: 47都道府県×平地/山地、季節・天気・気温・月齢、4つの採集方法、距離による移動費、保護種は見るだけ。1か月3回まで。見つけた個体から持ち帰るものを選ぶ。出発地の変更は有料
- ショップ: マット3種(10L袋)、ゼリー、産卵セット、飼育ケース3サイズ(大型種は大きいケースが必要。空きケースは半額で売れる)、委託販売、譲渡、標本依頼
- 繁殖: ペアリング、産卵セット、孵化、累代表示、サイズ遺伝(軽いモデル)
- 演出: 移動の読み込み画面、捕獲・購入のゲット演出、売却のSOLD演出

種データは環境省・自治体レッドデータブック等の公開資料にもとづく目安。数値(価格・相場・卵数・維持費など)は暫定です。商品名は一般名にぼかしています。

## 未実装

## 経済シミュレーション

`node tools/sim.js 100 24` で、`index.html` をそのまま動かして24か月の自動プレイを集計します(結果は `tools/sim-result.md`、考察は `docs/economy-sim-v0.2.md`)。

## 起動

`index.html` をブラウザで開くだけで動作します。

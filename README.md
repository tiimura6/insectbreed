# JF育成アプリ (insectbreed)

合同会社常北ファームの集客を目的とした、昆虫育成Webアプリ。

## 現状 (v1 プレビュー)

単一HTML(`index.html`)。状態はブラウザの localStorage に保存(端末をまたがない)。

- 育成: 個体別メーター、現実時間での劣化、「季節を次へ」で成長・蛹・羽化・寿命・死亡
- 採集: 8地域の地図、季節、4つの採集方法、時間帯・天気・月齢、保護種は見るだけ
- ショップ: 飼育用品(マット/ゼリー/産卵セット/ケース追加)、委託販売、標本依頼
- 繁殖: ペアリング、産卵セット、孵化、累代表示、サイズ遺伝(軽いモデル)

数値(価格・相場・卵数など)と種データは暫定です。

## 未実装

- ランキング(サーバー側集計が前提)、IP推定、図鑑画面、暖房・保温
- 店舗連携(QR等)は先送り

## 起動

`index.html` をブラウザで開くだけで動作します。

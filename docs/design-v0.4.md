## 1. 採集
- 採集先は都道府県(47)で選ぶ。画面は「地方タブ(8)→都道府県タイル」。さらに「平地(里山・雑木林)/山地(標高の高い森)」を選ぶ
- 都道府県ごとに、季節の区切りと気温の基準は地方の表を使い、一部の県だけ気温補正を入れる(例: 長野 -3℃、東京・神奈川・大阪・高知 +1℃)。値は目安で暫定
- 山地は平地より気温が約5℃低く、雨が出やすい(+10ポイント)。冬は気温2℃以下なら雪が出る
- 昆虫は「地方×都道府県の例外×地形」で変わる。種は12種+保護種5種(下の表)
- 時間は「1か月進める」ボタンで1か月ずつ進む(確定)。初期値は現実の月。戻すボタンなし。採集・飼育の両方が同じ月で動く。季節は月から決まり、変わったときに通知する
- 季節の区切り(月)
  - 北海道: 春4-5 / 夏6-8 / 秋9-10 / 冬11-3
  - 東北: 春4-5 / 夏6-8 / 秋9-11 / 冬12-3
  - 関東・中部・近畿・中国四国・九州: 春3-5 / 夏6-8 / 秋9-11 / 冬12-2
  - 沖縄: 春3-4 / 夏5-10 / 秋11 / 冬12-2(冬も雪なし、緑の森)
- 保護種は「見るだけ」で図鑑に載り、捕獲・売却・標本は不可(5種: ヤンバルテナガコガネ[沖縄島]、ヨナグニマルバネクワガタ[与那国島]、オキナワマルバネクワガタ、ウケジママルバネクワガタ[請島、鹿児島県]、ヒサマツサイカブト[南大東島])
- 出現条件: 時間帯、月齢(日付から計算)、天気(擬似乱数)、気温、採集方法、地形
- 採集方法(4種): 樹液 / 灯火(月明かり・風・雨で成果低下) / 朽ち木割り(割った木を元に戻す操作を入れる) / トラップ(夕方設置、翌朝回収)
- 表示: 採集画面の上部に、選んだ場所の天気・気温・月齢を表示。都道府県タイルには平地の天気・気温と移動費、地形ボタンには各地形の天気・気温を表示
- 採集は1か月に3回まで(v0.3。定数 GMAX)。月を進めると回数が戻る
- はじめての土地ボーナス(v0.4): 出発地以外の都道府県で初めて採集するとき、出現率(成虫・朽ち木の幼虫とも)を2倍にする(定数 FIRSTX。上限0.9)。初回のみ。訪問済みはセーブの `vis` に持つ。都道府県タイルに「初」の印を付ける。遠征する動機づけと、各地の虫を知る教育目的を兼ねる
- 持ち帰り(v0.3): 見つけた個体は候補として一覧に出し、プレイヤーが持ち帰る個体を選ぶ(合うケースに空きがあるものだけ)。選ばなかった個体は「捕まえずにその場に残す」扱いで、次の採集・月送り・「残りはその場に残す」で消える。捕まえた後に放す操作ではないので、放虫禁止の方針とは矛盾しない
- 図鑑の「捕獲」数は、持ち帰ったときに数える(見つけただけでは「見かけた」)

## 2. 出発地・移動費
- 出発地は現在地のみを持つ(自宅の概念なし)。初期値は茨城県。出発地は都道府県の一覧から変更できる。変更には、旧出発地から新出発地への移動費と同じ額がかかる(v0.3。確認画面あり。所持金が足りなければ変えられない)。これで「出発地を目的地に書き換えて移動費0」を防ぐ。IP推定で都道府県を候補表示→本人が確認、外れたら手入力、は未実装
- 移動費は出発地と目的地の直線距離(各県の県庁所在地付近の座標から計算)×5円/km、100円単位、他県は最低200円。同一都道府県内の採集は無料(例: 茨城→栃木 300円、茨城→沖縄 8,300円)
- 遠方は初期ポイントでは行けない設計で、確定(ユーザー確認済み)
- 実装前に外部のIP位置推定APIへ通信できるかを確認する

## 3. 経済
- 収入は委託販売のみ(採集・飼育した個体を売って稼ぐ)
- 支出: 道具(ライト、白布、バッテリー、トラップ餌)、移動費、飼育用品、標本依頼料、ケース維持費(ケースの大きさごとに月30/50/80円)
- 委託販売(実装済み): 出品者が自由に値付け。目安の価格帯のみ表示(正確な相場は隠す)。相場は種・サイズ・性別・状態・季節で決まる(夏は成虫が安く、冬は高い。羽化不全は半値)。売れる確率は希望価格と相場の比で決まり、月を進めたときに判定(従来の1季節ぶんの確率を3か月に割り振った値)。売れた場合は手数料10%を引いて入金。売れ残ると、月ごとに維持費30円がかかり、状態が7%ずつ落ちて値打ちが下がる。出品枠は「3+ケース数÷2(切り捨て)」(v0.4。初期のケース2個で4枠、最大8個で7枠)。ケースを増やす投資が売る量の上限に効くようにする。取り下げは、その種に合うケースに空きがあるときだけ
- 基準価格(暫定): オオクワガタ3,000円、ヒメオオ1,500円、ほかは従来どおり
- 売買不可: 保護種、特定外来生物。指定外の外国産は売買可。種データに「売買可否」項目を持たせる(法改正に追随)
- 放虫は一切できない設計(国産含む)。放すボタンなし。「放虫しない」ことを教える画面を置く
- 手放す出口: 委託販売 / 譲渡 / 飼い切り。譲渡は v0.3 で実装(ショップの委託販売欄。代金0、確認画面あり、取り消し不可。「ゲーム内で知人やイベントに無償で譲る」扱いで、野外に放すことではないと明記)。世話をやめて死なせる以外の処分手段を用意するのが目的

## 4. 飼育(実装済み)
- 時間の扱い: 日々の劣化は現実時間で進む(満腹度 -1.2/時、湿り -0.8/時、鮮度 -0.4/時。放置は最大72時間ぶんまで反映)。成長段階(幼虫→蛹→成虫)は「1か月進める」ボタンでのみ進む。1回押すと「飼育◯日目」が30日進む
- メーターは個体ごと。お世話ボタンは選択中の個体に効く
- 幼虫のエサ: 幼虫は、マット交換をすると自動でエサを食べる(確定)。「エサをやる」ボタンは幼虫では使えない。マット交換は1回1L使い、鮮度100・湿り50(深発酵は60)・満腹度100(浅発酵は85)になる。使うマットは3種から選ぶ
- 月を進めるときの判定: 管理項目が基準を下回った数で、0=順調 / 1=弱った / 2以上=危険。危険な個体は進める前に警告し、危険のまま進めたときだけ死ぬ
  - 幼虫: 満腹度・湿り・鮮度。順調なら成長(必要月数に達するまで体重が増える。上限40g)、弱ったら成長が遅れる(体重 -1g)、気温8℃未満なら成長停止。必要な成長月数(暫定): カブト6、ノコギリ8、ミヤマ8、コクワ8、ヒラタ12、スジ6、アカアシ8、オキナワヒラタ10、オキナワカブト6、オキナワノコギリ8、オオクワ12、ヒメオオ8。達すると蛹
  - 蛹: 湿りが基準。霧吹きは蛹室の外からの扱いで、触ったことにならない(v0.3)。それ以外のお世話ボタンを押すと羽化不全。弱った場合は50%で羽化不全。成虫の活動する季節(種ごとの出現の重みが一定以上)になるまで、蛹のまま待つ
  - 成虫: ゼリー残量・湿り・ケースの清潔。寿命(月数、暫定): カブト・ノコギリ・オキナワ3種・アカアシ2、ミヤマ1、スジ10、コクワ・ヒメオオ12、ヒラタ・オキナワヒラタ18、オオクワ24
- 月が進むたびに、全個体のメーターが下がる(満腹度 -14、湿り -10、鮮度 -10)
- 旧データ(季節単位)は、読み込み時に月単位へ自動変換する(成長月数は比例換算、成虫の経過は3倍)
- 飼育の気温は、出発地の都道府県・季節の平地の目安値(屋外想定。暖かい場所に移す機能は未実装)
- 失敗の表現は文章のみ。グロテスクな絵は出さない
- ケースの数とサイズが個体数の上限(6章)

## 5. 標本(実装済み)
- 対象は成虫のみ。寿命で死んだ、羽化不全でない個体だけが標本にできる(世話不足で死んだ個体は不可)。依頼料400円
- 依頼できるのは死亡直後(次に月を進めるまで)のみ
- 完成は次に月を進めたとき。ショップの標本一覧に、産地(都道府県・地形)・採集月・サイズのラベル付きで登録。累代個体は「累代 F◯」を併記
- 用途は図鑑のコレクションのみ(売却・展示は不可)
- 保護種は標本不可
- 殺す操作は設けない(死亡は寿命と世話不足のみ)
- 店はゲーム内のサービス。実店舗の標本作成とは切り離し、画面に「ゲーム内のサービスです」と明記する

## 6. 飼育用品ショップ(実装済み・価格は暫定)
- 方針(確定): ゲーム内の商品は、実店舗の商品・在庫・価格とは紐づけない。実在の商品名・画像・ロゴは使わず、一般的な呼び方だけを使う。仕入れ自動化のデータとも連携しない
- 価格の目安: 10Lのマットが800〜2,000円程度という一般的な相場感(ユーザー提供)を、ゲーム用に割り振った暫定値。実店舗の価格に合わせることはしない
- マット(20L袋。v0.4 で10L→20L、価格は据え置き。在庫はL単位。交換1回で1L使用)
  - 発酵が浅いマット: 800円。交換後の満腹度85
  - 標準的なマット: 1,300円。満腹度100・湿り50
  - 発酵が深いマット: 2,000円。満腹度100・湿り60
- 昆虫ゼリー40円/個、産卵セット600円/個
- 飼育ケース(大きさ別。合計最大8個)
  - 小型 800円(維持費 月10円、v0.2 は30円): ヒメオオ、コクワ、スジ、アカアシ
  - 中型 1,500円(維持費 月20円、v0.2 は50円): ミヤマ、ノコギリ、オキナワノコギリ、オオクワ
  - 大型 2,600円(維持費 月30円、v0.2 は80円): カブトムシ、オキナワカブト、ヒラタ、オキナワヒラタ
  - 売却(v0.3): 空いているケースは購入価格の半額で売れる。使用中のケース(売ると今の個体が収まらなくなる)と、最後の1個は売れない
  - 各種は、自分のサイズ以上のケースに入る。収容は、大きい種から順に、入れられる最小のケースへ割り当てて判定する(採集・孵化・出品の取り下げで使う)
  - 種のサイズは種ごとに固定(幼虫から成虫まで同じ)
  - 初期所持: 中型1、大型1。旧データは、持っていたケース数すべてを大型として引き継ぐ(v0.2 まではこの変換が効かず中型1・大型1になる不具合があった。v0.3 で修正)
- 消費: 成虫のエサやり=ゼリー1個。霧吹きと成虫のケース掃除は無料。不足するとお世話できない
- 初期所持: 標準マット5L、ゼリー3個
- 未実装の品目: 止まり木、暖房・保温用品。ケースの種類(産卵用の容器、成虫と幼虫で別の要求)はこれ以上細かくしない

## 7. 繁殖(実装済み・数値は暫定)
- ペアリング: 同種の成虫の雌雄が同じ場所にいるとき「ペアにする」で、未交尾の雌が交尾済みになる。傷つくリスクはクワガタ20%、カブトムシ5%(傷ついた雌は産卵数が半分)
- 産卵: 交尾済みの雌を選んで「産卵セットを組む」(産卵セット1個を消費)。次の月に産卵し、親は寿命で死ぬ(標本の対象になる)
- 卵の数(順調な場合): カブト15、ノコギリ18、ミヤマ12、コクワ25、ヒラタ20、スジ25、アカアシ15、オオクワ20、ヒメオオ12、沖縄の3種は15〜20。弱った雌は半分
- 孵化: 月を進めた後、合うケースに空きがある数だけ幼虫が生まれる(空きがなければ卵は孵化できない)。幼虫は初期5g、累代 F1, F2…を持つ
- サイズ遺伝(軽いモデル): 子の体サイズ係数は、親の平均サイズ比に応じて0.85〜1.15の範囲で動く。羽化時のサイズに掛かる
- 近親交配などの血統の詳細モデルは未実装

## 8. 演出(実装済み)
- 採集の出発: 読み込み画面を出す。距離で表現が変わる(同じ県=徒歩1.3秒、約400km未満=電車2.0秒、それ以上=飛行機2.8秒)。画面には移動先、距離、費用、進行バー、採集のヒントを表示
- 捕獲: 結果の前に「ゲット!」の演出。捕まえた個体をカードで順に表示し、初めて捕まえた種には「NEW」、保護種は「発見!」として見るだけ。何も採れなかったときは「空振り」の表示
- ショップ: 入店時の読み込み(0.7秒、お店のドアと鈴)。購入すると、品物のアイコンつきの「ゲット!」演出(マットは発酵の深さで色が違う)
- 委託販売: 月を進めて売れたとき、コインが降る「SOLD」の演出と売却額を表示し、終わってから月の結果を出す
- v0.4 で追加したアニメーション
  - 月送り: カレンダーがめくれる演出(1.7秒、タップで飛ばせる)。季節が変わったときは季節のアイコンと、桜の花びら・ホタル・落ち葉・雪の粒子
  - 月の出来事: 羽化(個体カード)・孵化(卵が並ぶ)・蛹化をまとめたカードを、委託の SOLD 演出のあとに出す。その後に月の結果
  - お世話: 霧吹き=水滴、マット交換=土が落ちる+個体が跳ねる、ゼリー=ハートが上がる+跳ねる、掃除=光が横切る、蛹に触れた=ケースが揺れる
  - 待機: 幼虫はゆっくり身をよじる、成虫はケース内を左右に歩き脚を動かす、蛹はときどきぴくっと動く
  - 採集画面の森: 冬は雪、秋は落ち葉、春は花びらが降る。夏の夜・明け方はホタル
  - ポイント: 増減を0.6秒で数え上げ、増えたら緑、減ったら赤く光る
  - 画面切り替え: 横から少しスライドして入る。ボタンは押すと少し縮む
  - 持ち帰り: 「持ち帰る」を押すとカードが横に抜ける
- 「視差・動きを減らす」設定のとき(prefers-reduced-motion)は、読み込みを短くし、購入・売却・空振りの演出を省く(捕獲カードは表示する)。v0.4 の追加分(月送り・出来事カード・お世話・待機・粒子・ポイント・スライド)もすべて止める

## 9. 実装状況(プレビュー版)

## 10. 要対処のリスク

### v0.3 の再シミュレーションで残った課題(v0.4 で対処。結果は検証レポート6章)(詳細は `docs/economy-sim-v0.2.md` の5章)
- ケースを買い増しても、24か月以内に元が取れない。拡大投資が報われず、成長の手応えがない
- 孵化から成虫まで育てると、全種でまだ赤字(主因はマット代。月あたり約65円)
- 遠征は期待値で地元に勝てない(遠征する理由がない)
- 持ち帰りを選べるようになり、オオクワの捕獲は年1匹→2〜3匹(入れ替え方針)。売上に占める割合は最大37%。今のところ経済は崩れていない

### v0.2 時点のリスク(一部は v0.3 で対処)
- 経済の調整: 月送りと商品価格の変更を入れた直後で、収入と支出の釣り合いは未検証。初期のケース2個(中型・大型)の維持費は月130円、幼虫のマット交換は1回80〜200円
- 世話の手間: 幼虫は月ごとにマット交換が必要になり、長く育てる種(ヒラタ・オオクワ12か月)ほど費用と手間がかさむ。実際に遊んで調整する
- 繁殖の増殖: 卵数は多いが、孵化は合うケースの空きが上限。大型種を増やすには大型ケース(2,600円)が要る。ケース価格とのバランスを見る
- 繁殖で作った個体を売り続ける無限増殖の経済: 維持費とマット代で抑える想定だが未検証
- 小型ケースで済む種(コクワなど)に偏ると、大型種を飼う意味が薄れる。大型種の売値を高くするなど、価格での調整が必要になる可能性がある
- 地形による差が小さい県(例: 千葉・佐賀)にも山地を出している。実在の山の有無は未反映
- オオクワガタは希少で高価な設定のため、出現率(基準0.08)と価格(3,000円)で経済が崩れないか要確認
- 集客との接続: 実店舗の商品と紐づけないため、アプリから来店・購入へつなぐ導線は、いまの設計には無い。QR連動の先送り(目的の達成手段)とあわせて、別の導線を後で決める必要がある

## 11. 資料の扱い(法的な整理)
- 事実(分布、大きさの範囲、発生時期)は著作権の対象ではないが、雑誌の文章、図表、データの選び方と並べ方は著作物になり得る。そのため、文章や表をそのまま写さず、環境省、自治体のレッドデータブック、博物館・大学・図鑑サイトなどの公開資料で裏づけた事実だけをアプリの値に反映する
- 専門誌ビークワの記事は、本文を読める状態になっていないため、今回の反映には使っていない。ユーザーが自炊した資料を使う場合は、(1)自分が値を確認するための参照に限る、(2)アプリや公開データへは、公開資料で裏づけた値だけを入れる、(3)文章の言い換えを公開しない、を前提にする
- 画面には「公開資料にもとづく目安で、ゲーム用に簡略化している」旨と、保護種の指定は環境省の最新一覧で確認する旨を表示済み
- 商品名は、実在の商品名を使わずに一般名にする(6章)
- 主な出典: 環境省 特定外来生物等一覧、環境省 沖縄奄美自然環境事務所「奄美沖縄の国内希少野生動植物種」(令和6年2月)、京都府レッドデータブック(オオクワガタ)、兵庫県レッドデータブック(ヒメオオクワガタ)、兵庫県の昆虫館資料、帯広畜産大学の北海道十勝のクワガタ調査、宜野湾市立博物館の資料

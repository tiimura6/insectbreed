# 経済バランス検証レポート(v0.2 の数値のまま)

- 対象: `index.html`(main, ffebf05)。**本体の数値は変えていない**
- 手法: `tools/sim.js` が `index.html` のスクリプトをそのまま Node の vm で動かし(ロジックを複製しない)、方針ごとに24か月を自動プレイ。100回×11方針×4条件(1日1回プレイ/一気に月送り × 開始11月/5月)
- 生データ: v0.2 は `tools/sim-result-v0.2.md`、v0.3 は `tools/sim-result.md`(`node tools/sim.js 100 24` で再現)

## 1. 結論

1. **インフレではなく「デフレ(じり貧)」の経済**。大半の方針で24か月後の残高の中央値は初期の1,280ptを下回る。黒字になるのは「ケースを買わず、相場の7割で売り続ける」方針だけ(24か月で +3,500〜4,300pt、月 +150〜180pt)
2. **(a) 初期資金**: 破綻はしない(残高は0で止まり、地元の樹液採集は無料なので続けられる)。ただし、UIの初期価格(目安帯の中央)のまま出品すると、半数が24か月以内に残高0付近に落ちる
3. **(b) 繁殖での無限稼ぎ**: **起きない**。理由は3つ: ①雌は1回産卵すると死ぬ ②出品枠4 ③ケース維持費。オオクワのペア・中型8個・1万ptから始めても、24か月で1万ptが1,000〜3,300ptに減る
4. **(c) オオクワ**: 経済は崩れない。捕獲は年1匹前後で、売上に占める割合は20%台。むしろ「当たりを引いても報われない」側に寄っている
5. **(d) 小型ケース種への偏り**: 起きない。偏りは「小型種」ではなく「**地元に多い安い種(コクワ・スジ)**」に起きる。コクワ繁殖特化は最も成績が悪い方針の一つ
6. 数値より先に直すべき**仕様の穴**が5つある(3章)。数値調整はその後でないと意味がない

### 種ごとの理論値(孵化から育てて成虫で売る場合)

全12種で **赤字**(1匹あたり −620〜−2,105pt)。成長月数+冬の成長停止で10〜18か月かかり、ケース維持費とマット代が成虫の相場を上回る。損が最も小さいのはオオクワ(−44pt/ケース月)とヒメオオ(−48)。

## 3. 仕様の穴(数値以前の問題)

| # | 穴 | 根拠(コード) | 影響 |
|---|---|---|---|
| 1 | **出発地の変更が無料・無制限** → 目的地を出発地にすれば移動費0。「遠方は初期ポイントで行けない」(確定事項)が成立しない | `locsel.onchange` で `s.loc` を即変更、`travelCost(s.loc,dest)` | 確定事項の破綻。相場の季節判定・飼育気温も出発地依存なので、北海道に切り替えて冬相場(×1.4)で売る、沖縄に切り替えて冬も成長させる、も可能 |
| 2 | **1か月の採集回数が無制限**(採集は日を1日進めるだけ) | `runGather` は `s.day+=1` のみ | 月送りの意味が採集側で薄い。天気も日ごとに引き直される |
| 3 | **持ち帰る個体を選べず、手放す手段が委託(4枠)しかない** → ケースが安い個体で詰まる | `runGather` で `found` をシャッフルして先着順に収容 | オオクワ狙いでもコクワ幼虫で枠が埋まる。結果として「世話をやめて死なせる」が実質的な処分ボタンになる(確定事項「殺す操作なし」の抜け道) |
| 4 | **蛹は何をしても乾く** → 世話すると「触った」扱いで羽化不全確定、世話しないと湿りが30を切り50%で羽化不全 | `care()` は蛹なら種類を問わず `touched=true` | 1日1回プレイで羽化不全率36〜50%。標本も作れなくなる |
| 5 | **ケースを手放せない** → 買いすぎると維持費で残高0まで削られ続ける | ケース売却・廃棄の処理なし | 「ケースを増やすほど損」になり、投資の判断が成立しない |

補足(数値の不整合):
- オオクワの終齢幼虫(21g)の相場 ≒ 2,360pt > 成虫の雌雄平均(夏) ≒ 1,780pt。幼虫で売る方が得になりうる
- 残高は0で止まり借金にならない(ケース費・委託維持費が `Math.min(fee, pts)`)。失敗の圧力がない一方、0からの立て直しは無料採集のみ
- 遠征は期待値で見て、ほぼ常に地元に負ける(移動費に見合う値段の種がいない)

## 4. 調整案

### 4-1. 仕様の穴への対処(どれを採るかはユーザーが決める)

| 穴 | 案A(軽い) | 案B(重い) |
|---|---|---|
| 1 出発地 | 出発地の変更に移動費を取る(移動と同額) | 出発地の変更は月1回まで、かつ有料。相場と飼育気温は「自宅」に固定(自宅の概念を復活) |
| 2 採集回数 | 1か月の採集を3回までに制限 | 採集ごとに「体力」を消費し、月送りで回復 |
| 3 持ち帰り | 捕獲結果から持ち帰る個体を選ぶ画面を足す(見送りは放虫ではなく「その場で見送る」の扱い) | 案A+「譲渡」(0円で即手放す。確定事項の「手放す出口」に既にある) |
| 4 蛹 | 蛹は霧吹きだけ可(触った扱いにしない) | 蛹室の湿りは幼虫最後のマット交換で固定し、待機中は減らさない |
| 5 ケース | ケースを半額で売れる | 空ケースは維持費0(使用中だけ課金) |

### 4-2. 数値(穴を直した後に再検証する前提)

| 軸 | 案1: 収入を上げる | 案2: 支出を下げる | 案3: 時間を縮める |
|---|---|---|---|
| 内容 | 委託手数料10%→5%、出品枠4→6 | ケース維持費 30/50/80 → 10/20/30 | 成長月数を約半分(オオクワ12→6、カブト6→3など) |
| 利点 | 価格調整だけで済む。売る楽しさが増す | 「育てると赤字」がほぼ解消。繁殖が意味を持つ | 現実の飼育期間から離れるが、遊ぶテンポが上がる |
| リスク | 繁殖場が黒字化しやすくなる(枠×単価で上限が上がる) | ケースを買い込む方針が強くなる(上限8で抑えられる) | 公開資料に基づく「目安」から外れる。教育目的と衝突 |
| 推奨条件 | 短期で手触りを良くしたい | 中長期で繁殖を主軸にしたい | 1回の遊び時間を短くしたい |

推奨: **4-1の穴1・3・4・5を先に直し、案2(維持費の引き下げ)を軸に再シミュレーション**。案3は教育・事実重視の方針と衝突するので最後の手段。

| 穴 | 採った案 |
|---|---|
| 1 出発地 | 変更に移動費と同額を取る(確認画面あり) |
| 2 採集回数 | 1か月3回まで |
| 3 持ち帰り | 見つけた個体から選ぶ。選ばなかった個体は「捕まえずにその場に残す」。加えて譲渡(0円)を実装 |
| 4 蛹 | 霧吹きは触った扱いにしない |

### 5-2. 結果(1日1回プレイ・開始11月、100回の中央値。v0.2 → v0.3)

| 方針 | 24か月後 v0.2 | 24か月後 v0.3 | 羽化不全率 v0.2 → v0.3 |
|---|---|---|---|
| 放置 | 0 | 80 | 50% → 0% |
| 地元採集→UI既定価格 | 45 | 2,604 | 43% → 0% |
| 地元採集→相場の70% | 4,811 | 8,051 | 36% → 0% |
| 上限まで採集+ケース増設 | 981 | 1,990 | 39% → 0% |
| オオクワ狙い+繁殖 | 433 | 682 | 43% → 0% |
| 安い個体を譲渡して入れ替え(v0.2 は放置死) | 899 | 3,145 | 4% → 0% |
| 上限テスト: オオクワ繁殖場(1万ptから、孵化直後に売る) | 1,059 | 13,659 | 0% → 0% |

- (a) 初期資金: UI既定価格でも中央値は黒字に転じた。最低残高の中央値は約1,000ptで、序盤に詰まらない
- (b) 無限稼ぎ: 起きない。最も効率の良い繁殖場でも24か月で +3,700pt。その大半は空きケースの売却額。出品枠4と「雌は1回産卵で死ぬ」が上限になっている
- (c) オオクワ: 持ち帰りを選べるため、入れ替え方針での捕獲は年2〜3匹、売上に占める割合は37%。崩れてはいないが、v0.3 で最も効く値になった。次に上げるなら出現率より価格を見る
- (d) 偏り: 売れた種の上位はコクワ・ヒラタ・スジで、地元に多い種。小型ケースの種には偏っていない

### 5-3. 残った課題(次に決めること)

1. **ケースを買い増しても元が取れない**。「上限まで採集+ケース増設」(相場の80%で出品)は、ケースを買わない「相場の70%で出品」より24か月後に約6,000pt少ない(出品価格の差も一部含む)。拡大する意味がない
   - 案A: 出品枠をケースの数に連動させる(例: ケース2個ごとに +1枠)
   - 案B: 大型・中型の種の基準価格を1.5倍にする
2. **孵化から育てると全種でまだ赤字**。主因はマット代(1日1回プレイで月約65円/匹)
   - 案A: マット1袋の量を10L→20Lにする(価格はそのまま)
   - 案B: 幼虫の満腹度の減りを月-14→-7にし、交換の頻度を半分にする
3. **遠征する理由がない**。期待値で地元に負ける
   - 案A: 遠方の地域にしかいない種の基準価格を上げる
   - 案B: 初めて行く都道府県では出現率に上乗せする
